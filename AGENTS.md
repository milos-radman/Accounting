# Agent orientation

Start with **[`DEMO_DEPLOYMENT.md`](DEMO_DEPLOYMENT.md)** — current status, next steps and
scope rules for the active work (demo deployment to IIS + SQL Server). Keep its status table
and progress log updated as you work; it is the only planning file in this repo.

Then read **[`CLAUDE.md`](CLAUDE.md)** for repo layout, build/test commands and conventions,
and **[`README.md`](README.md)** for domain background.

**Scope rule:** the goal is a **presentable demo** for testing and concept investigation —
not a production system. Prefer the fewest steps and least code that genuinely works.
